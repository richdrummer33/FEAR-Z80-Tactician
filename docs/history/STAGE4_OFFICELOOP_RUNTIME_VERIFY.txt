Rendering
---------
Logical world: 46 x 24 cells
Cell size: 4 x 4 pixels
World pixel size: 184 x 96
Visible horizontal logical span: 40 cells
Horizontal camera range: 0..24 pixels (six logical columns)
Vertical scrolling: unnecessary for office-loop

Terrain is packed four logical cells per 8 x 8 VDP background pattern. Runtime pattern
caching found only fourteen distinct 2 x 2 terrain combinations on the authored map,
which eliminated the original multi-second startup cost of uploading 276 unique patterns.

HUD scrolling fix
-----------------
The SMS/GG VDP's R0 horizontal-scroll inhibit only applies when the absolute VDP scanline
is below 16. Game Gear's visible 144-line window is vertically cropped from the SMS image,
so those lines are above the visible Game Gear HUD. Stage 4 therefore uses a scanline
interrupt: VBlank sets horizontal scroll to zero for the HUD, then the line interrupt
applies camera scroll for the battlefield below it.

Performance notes
-----------------
The first naive 46 x 24 / many-agent implementation spent hundreds of video frames per
logical tick because long-range movement repeatedly searched the entire 1104-cell map.

The final stage uses the six-room / seven-door authored graph for long-range waypoints,
greedy local movement for obvious steps, and tile BFS only as fallback. Cached paths also
wait rather than rebuilding when another actor temporarily blocks the next cell.

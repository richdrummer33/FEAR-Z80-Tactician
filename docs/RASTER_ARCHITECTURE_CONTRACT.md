# Raster architecture contract

Frozen so that later work is measured against it rather than drifting from it.
Everything here is established by experiment; the log records which rung.

## The shape

```
STATIC BAKED GEOMETRY                     per cell / span / vertex, pose-free
  cell, span and vertex identity
  local projection coefficients           bearing = base + Ax*lx + Ay*ly
  wall normal class, depth-plane factors  nf_q7[class][yaw], stepfac_q4[class][yaw]
  inverse-depth baseline
        |
        v
ARBITRARY DESTINATION POSE                cell + local x,y + yaw, any delta
        |
        v
CHEAP POSE-DEPENDENT STATE
  endpoint relative bearings  rel, len
  screen columns              c0, c1
  inverse depth               invd
  depth plane                 iq, step
  DDA phase                   (iq + 32) mod 1024
  span length                 external
        |
        v
GENERIC RASTER STREAM SELECTION           <- the open engineering question
        |
        v
PACKED REPLAY
```

## The rules

1. **No sampled-pose keys.** Baked metadata describes geometry or a generic
   transformation of it. `"at sampled pose 37 use program 219"` is the dictionary
   this investigation exists to undo. `"this span has these static depth and
   projection properties; at the arbitrary destination pose these few operations
   yield the canonical raster state"` is the contract.
2. **Destination evaluation is the foundation; certificates are shortcuts.**
   Correctness never depends on how far the player moved or on replaying what was
   crossed. Rung 6: 1,100,367 arbitrary `(dx, dy, dyaw)` cases, including
   multi-cell jumps, reproduce the renderer exactly.
3. **Retain generating state, never quantised output.** Twice measured: the
   raster trajectory is generated by `phase + step`, and the screen column is
   generated by relative angular state. Retaining `c0,c1` gives 86.97%
   successor conflicts; retaining `rel,len` gives **0.00%**.
4. **Span length and absolute screen placement stay external** wherever possible.
   They are world-specific; the generic machine should not encode termination.
5. **Margins, not counters.** A certificate is a region test on the destination
   pose, not a decrement. Per-axis margins are not composable (5.35% X+Y,
   11.06% X+yaw), so the region is a polyhedron, not a box.

## What is settled

| Question | Answer | Evidence |
| --- | --- | --- |
| Does arbitrary-pose generic rasterisation exist? | yes | Rung 6, 1.1M cases exact |
| Is the output vocabulary finite? | yes, 432 | 2,675,675,264 instances, every walkable cell |
| Does the DDA have a compact underlying state? | yes, 10-bit phase + step | proved, then checked over 2.27M comparisons |
| Does yaw need incremental stepping? | no | `rel' = rel - dyaw*16`, exact for any delta |
| Is the ROM depth plane the faithful derivation? | yes | worst 2.69 px vs the host path's 40.34 px |

## What is open

**How few Z80 instructions turn baked geometric state plus the current arbitrary
pose into the ID or address of the correct generic raster stream?**

That is the selector. It is not a newly discovered unknown — the projection,
depth-plane and cell-metadata work already decomposed it — and the candidate
solution family is named above. What the race added is a measured value for
solving it well, and the elimination of one expensive way of doing it.

## Dead, and what survived it

**BAND as an execution strategy is dead.** It loses to the plain DDA at every
span length because building a band's program is itself a six-column DDA.

**Band boundaries as mathematics are not dead.** `p = (-c*step) mod 1024`
describes exactly where six-column raster behaviour changes, and that is the
material for the temporal certificate whether or not BAND ever draws a pixel.
An experiment can lose the implementation race and still contribute the
mathematics.
